An entry for the [make.fun](https://make.fun) bounty
[Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.py` writes one short text to `/output/entry.txt` — a quiet room for a
reader who has been reading a long time. It is deterministic, uses no network,
and needs nothing but Python 3.13.

Run it:

```sh
python3 main.py
```
